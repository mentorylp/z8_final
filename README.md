# Голос — децентрализованное голосование

Приложение на [Scaffold-ETH 2](https://github.com/scaffold-eth/scaffold-eth-2): смарт-контракт Solidity, локальная сеть Hardhat и интерфейс Next.js с RainbowKit. Любой подключённый адрес может создать голосование и проголосовать один раз в каждом из них. Вопросы, варианты, сроки и результаты хранятся в блокчейне.

## Локальный запуск

Требуются Node.js 22.10+ и Yarn 4. 

```bash
yarn install
```

В трёх отдельных терминалах из корня проекта:

```bash
yarn chain
yarn deploy
yarn start
```

Откройте [http://localhost:3000](http://localhost:3000). Для локальной сети Scaffold-ETH 2 предоставляет тестовый кошелёк и кран. После перезапуска сети повторите `yarn deploy`, поскольку локальное состояние блокчейна сбрасывается.

## Проверки

```bash
yarn compile
yarn test
yarn lint
yarn next:build
```

Смарт-контракт работает без администратора и не использует сервер для подсчёта голосов. Голосование открытое: адреса, выбранные варианты и результаты видны всем. Правило «один адрес — один голос» **не подтверждает личность** и не защищает от создания нескольких адресов. Транзакции создания и голосования требуют оплаты газа в выбранной сети.
